🔍 Live Multi-Hop Collaborative Filtering Cypher Query

Cypher 5.x 
MATCH (me:User {id: $userId})
MATCH (similar:User)-[simEdge]->(common:Movie)<-[myEdge]-(me)
WHERE (type(simEdge) IN ['RATED', 'BOOKED']) AND (type(myEdge) IN ['RATED', 'BOOKED'])
MATCH (similar)-[recEdge:RATED]->(rec:Movie)
WHERE recEdge.rating >= 4.0
  AND NOT (me)-[:RATED]->(rec)
  AND NOT (me)-[:BOOKED]->(rec)
RETURN rec.title, count(DISTINCT similar) AS graphMatchScore, collect(DISTINCT common.title) AS sharedTaste
ORDER BY graphMatchScore DESC LIMIT 5;
